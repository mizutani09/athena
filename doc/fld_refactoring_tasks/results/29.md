## Changes

- `run_suite.py` now creates a per-case `build_source/` containing
  `configure.py`, `Makefile.in`, and the current `src/` snapshot, including
  uncommitted source changes. Configure/build therefore write only below the
  case output directory.
- `--no-build` checks the selected existing binary with `-c` and rejects the
  expected pgen or fixed validation configuration mismatch before execution.
- The manifest now stores source/input/binary/configured-file/external-file
  SHA-256 values, effective settings, compiler and MPI versions, a limited
  environment allowlist, separate analysis/calculation provenance, command
  timeout/exit records, reached cycle, and termination reason.
- Calculation and plot-only analysis provenance are distinct. Downloaded
  plot-only runs keep their heavy HDF5 data in place and archive only small
  metadata files.
