## Implementation

- `RadFLD::FluxLimiter` now switches to the inverse-R form for `R > 1`, and
  `FluxLimiterTimesR` is evaluated directly from that form. `EddingtonFactor`
  uses this shared `lambda*R` value, so `R=1e155`, `R=Real max`, and `R=+Inf`
  do not create the old `R*R` overflow or `0*Inf` NaN.
- `RadFLD::EvaluateClosure` is the common gradient/opacity/Er closure. It
  explicitly defines zero gradient, zero opacity, and zero Er limits. For a
  transparent non-fixed face, `lambda/sigma` is evaluated as
  `(lambda*R)*Er/|grad Er|`; its zero-opacity streaming limit is therefore
  finite. Fixed limiter remains `lambda=1/3`; zero opacity is rejected when a
  finite nonzero-gradient diffusion coefficient would be required.
- Face opacity means avoid `0/0` and overflow in arithmetic/harmonic means.
  NR-FLD now uses the shared face opacity and closure coefficient for all six
  directions; Marshak's lagged face coefficient remains the same stored
  coefficient.
- Opacity callbacks reject negative/non-finite values at the producing cell.
  Negative/non-finite radiation energy is rejected before reconstruction or
  NR face stencils. These inputs are not silently floored; zero is allowed.
