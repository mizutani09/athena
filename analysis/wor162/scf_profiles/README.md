Both use 2048 radial points, 32 Gauss-Legendre angular points, multipoles
through `l=20`, domain radius `1.2 R`, SCF tolerance `1e-7`, and relaxation
0.5.  The command is the same for both except for the three output paths and
`OMEGA`:

```sh
$BSCF/bin/axisymmetric_scf PROFILE.csv METADATA.json HISTORY.csv \
  1.1340371006082187e34 3.0416236278576873e34 \
  6.229918027862565e13 1.1799231785218195e33 \
  3.541497158802513e11 2.3830036150993391e-4 \
  1.7863997481317117e11 3.541497158802513e11 \
  3 1.5 0.6353437771420501 4096 1e-6 180 \
  2048 32 20 1.2 OMEGA 0.5 1e-7 200
```

Use the common relaxation input with these command-line overrides:

```sh
# Nonrotating
problem/scf_profile_file=data/ic/rsg21_scf_omega0.csv \
problem/angular_velocity_rad_s=0 \
problem/atmosphere_reference_radius_cm=6.2299115623352812e13 \
problem/surface_polar_radius_cm=6.2299115623352797e13

# Slow rotation
```
