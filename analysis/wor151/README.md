# WOR-151 result set

This directory contains the reproducible C++17 audit of the selected MESA RSG baseline.

- `source_manifest.json`: upstream saved-model and exported-profile provenance.
- `mesa_profile_inventory.csv`: 118 locally available MESA profiles audited at selection time.
- `mesa_rsg_metadata.json`: boundary rules, units, source hash and interpolated states.
- `mesa_rsg_layers.csv`: 1,625-zone center-to-surface derived profile.
- `mesa_rsg_layers.svg`: dependency-free diagnostic figure generated by the C++ analyzer.
- `core_cut_sensitivity.csv`: 4 x 4 threshold sensitivity matrix.

The numerical implementation is `tools/mesa/analyze_rsg_profile.cpp`. Run its unit and reference gates with:

```bash
tests/mesa/run_wor151_cpp.sh /path/to/LOGS/profile1.data /tmp/wor151_check
```

The exact accepted profile is required by the reference SHA-256 gate. To regenerate the committed result set, pass `analysis/wor151` as the second argument.
