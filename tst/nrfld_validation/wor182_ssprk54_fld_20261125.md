# SSPRK(5,4) FLD transport validation (WOR-182)

Date: 2026-11-25

## Purpose

Verify the SSPRK(5,4) FLD path after restoring the stage-four saved-register
contribution in `IntegrateRADFLD`.  The test isolates smooth explicit FLD
transport, so the measured convergence is not limited by the implicit
gas-radiation exchange solve.

## Reproduction

- Script: `analysis/wor182/xd_ssprk54_fld_transport_convergence.sh`
- XD job: `347689`
- Integrator: `ssprk5_4`
- Spatial reconstruction: `xorder=4`
- Resolutions: `N=16, 32, 64`
- Final time: `0.05`

## Result

| N | L1 error | observed order |
|---:|---:|---:|
| 16 | 9.47535e-7 | - |
| 32 | 5.33324e-8 | 4.1511 |
| 64 | 3.34480e-9 | 3.9950 |

The finest pair recovers fourth-order convergence.  The values also agree
with the established fourth-order RK transport result to roundoff at N=32
and N=64.  This validates the repaired SSPRK saved FLD register for smooth
transport.  It does not by itself establish fourth-order accuracy for the
full operator-split implicit FLD system.
