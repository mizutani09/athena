## Job group B: matched-time CFL test on a resolved mesh

Once a cap keeps the core adequately resolved through `t=2106.5796`, run CFL=0.3 and 0.15 from the same physical initial state with identical AMR cap and output times. Start both fresh if the CFL change would otherwise inherit an already underresolved checkpoint. Compare volume-weighted core-only density, gas temperature/pressure, radiation energy, central octant ratio, density maximum, and radial profiles at matched physical times. Report the actual dt series; compare at two or more later times before any first-core claim. Do not use the ambient-only CFL difference as the deciding metric. Keep the Semenov table/guard identical in both runs. Record Newton iterations, every FGMRES true residual and componentwise backward error, local gas-solve residual, rejected/accepted opacity-domain diagnostics, and mesh changes.

The inner FGMRES target is `2e-8`. A bounded inexact result below `1e-7` may be accepted **only** if the following Newton stage converges and the energy and componentwise residual checks remain sound. Raising the FGMRES iteration limit alone is not a resolution remedy. The early local extra-AMR run saw one `2.189e-8` true residual and still converged nonlinearly; its next regrid step met the strict inner target.

## Job group C: first-core continuation and convergence

Only after groups A/B establish a stable resolved trajectory, continue to the first saved state with `rho_max >= 1e-10 g cm^-3`. The current 32³ input has a root cell width of 375 AU; `numlevel=13` would allow about 0.092 AU finest cells. That is merely an **initial capacity estimate**: at `rho=1e-10 g cm^-3` and an illustrative 100 K sound speed, 32 Jeans cells require roughly 0.1 AU, and the actual Tomida EoS temperature and sound speed must set the needed cap. Start with enough AMR capacity from the initial or an adequately resolved state, and increase it before the Jeans criterion fails. Check block count, memory and wall time in short segments; use handled termination to save restarts.
