## WOR-25: octet→MeshBlock の実補正

上向き V-cycle の該当箇所で、fine 2³ セルへ実際に渡した補正の作用 `R A_h P e_H` と octet の `A_H e_H` を比較した。fine の ghost は境界通信後に評価し、FAS の場合は `u_H-u_H^old` を使う。octet から MeshBlock 最粗セルにコピーされた補正自体も別に照合した。1/2 rank の全ローカル MeshBlock を集計し、rank 0 の一ブロック標本には限定しない。

| 条件（初回 V-cycle） | `||RA_hP-A_H||/max(||RA_hP||,||A_H||)` | FGMRES 総反復 | Newton |
| --- | ---: | ---: | ---: |
| fixed、aligned、`q=1e7` | 0.03391 | 17 | 2、PASS |
| fixed、shifted、`q=1e7` | 0.04139 | 18 | 2、PASS |
| variable、shifted、`q=5e5` | 0.69774 | 14 | 1、PASS |
| fixed、高 contrast `1e4`、shifted、`q=1e7` | 0.38509 | 17 | 1、PASS |
| coupled variable、shifted、`q=1e4` | 0.07001 | 202 | 20、PASS |
| fixed、shifted、`q=1e7`、FAS=true | 0.04872 | 34 | 2、PASS |

各 shifted 条件の 1/2 rank で作用素差は一致し、コピーした補正の相対 L2 差は全件 0。FAS=true も 1/2 rank で同じ値を得て、診断 ON/OFF の HDF が一致した。診断付き run は保存済み対照と HDF 全データが一致した。高 contrast や可変係数で作用素差は大きいが、FGMRES は真残差目標を達成した。したがって、この差だけを MG から Newton への転送不具合とは判定できない。前回の MG 単独 shifted 失敗と初回低周波残差減少の関係は残る。最粗段からの誤差固有モードへの直接投影はまだ行っていない。

## WOR-23 / WOR-24: coupled 2変数と Schur の全領域 Jv

periodic Test C に、独立したガス・放射方向の有限差分と、実際の Newton 放射方向を局所ガス行で消去した Schur 方向の診断を追加した。放射方向の ghost は FGMRES 補正と同じ通信経路で同期した。生の `Fr` と `Fg` は強い熱結合で桁落ちするため、Schur 差分は production の安定化右辺と同じ `Ftotal-Fg/dFg_deg` から計算し、消去係数は基準状態に固定した。係数・limiter は 1 Newton solve 中で lagged のままにした。

fixed/variable limiter × uniform/aligned/shifted × 1/2 rank の選んだ 8 条件は全て完走し、診断 OFF の既存 run と final HDF 全データが一致した。独立2変数方向の `h=1e-4` で全域ガス/放射 Jv 相対 L2 は約 `3.0e-5～3.9e-5`、Schur は約 `3.0e-5～4.7e-5`。AMR 粗細面の Schur は aligned fixed で `5.29e-5 → 5.29e-6 → 5.31e-7`、shifted fixed で `5.05e-5 → 5.04e-6 → 5.15e-7`（`h=1e-4,1e-5,1e-6`）。この一次減少は非線形有限差分の切断誤差と整合する。`h=1e-7` では丸め誤差が現れる。実 Newton 放射方向の消去 Schur は、shifted fixed の粗細面で `h=1e-4` 時 `2.35e-8`、1/2 rank は一致した。FGMRES 真残差と保存性は診断 OFF と同じ出力であり、数値解は変わらない。

物理境界は、保存的演算子が許可する Mach 5 の **user x1 / periodic transverse** を選び、mixed drift を無効にした 9 leaf MeshBlock の静的 AMR で追試した。[入力](wor25_23_24_mach5_physical_followup.in) は粗細面と user 境界の両方にセルを置く。`h=1e-4 → 1e-5` で Schur 相対 L2 は粗細面 `2.32e-5 → 2.32e-6`、物理境界 `3.42e-6 → 3.42e-7`。全域のガス/放射 Jv も概ね 10 倍減った。1/2 rank × 診断 ON/OFF の4 run は全て Newton 5回で収束し、FGMRES の明示真残差は `1e-8` 以下。最終時刻 `7.963941310512613e-5` の double-HDF 全ブロック全データ、topology、履歴は4 run で一致し、ρ・圧力・Er は正だった。物理境界からの入出流量を積分した保存予算はこの縮小 run では評価していない。

Mach 5 の既定 mixed-frame drift を有効にすると、この coupled global Jv 診断は明示的に拒否する。これを無効にした追試で物理境界と AMR の Schur 作用素を分離して検証したが、mixed-frame を含む完全な coupled Jacobian は引き続き未検証である。
