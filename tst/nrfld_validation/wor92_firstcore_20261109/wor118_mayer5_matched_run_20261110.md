# Matched ideal-EOS, constant-opacity first-core reference (2026-11-10)

## Purpose and controlled comparison

Re-run the Section 5 style nonrotating, unmagnetized 1 M☉ / 3000 au / 14 K sphere from cycle 0 with the validated WOR-118 source `ff60f8f07842acb00e7753932bcfe30867e3a66e`. The comparison target is the corrected table-EOS/Semenov full path at c1080, not the older ideal-gas job 335063 (different source and spatial resolution).

The [input](wor118_mayer5_matched_20261110.in) is copied from `wor118_c0_full_20261109.in`, changing only the build EOS to `adiabatic`, setting `hydro/gamma=5/3`, removing table-EOS keys, disabling the opacity table and its domain guard. `radiation/kappa_P=kappa_R=1 cm²/g`. Mass, radius, initial temperature, μ, ambient density and pressure ratios, fixed ambient temperature/radiation, Cartesian domain, Jeans AMR target `N_J=32`, CFL 0.3, RK2, flux limiter, radiation pressure in the Riemann solver, Newton–FGMRES–MG controls, and all WOR-118 conservative/face corrections stay the same. The input SHA-256 is `df33295cf4a9c25ad720bd36f22771596be469a36af3d6481c8c255e0eec3053`. Because the EOS is selected at compile time, build the identical source in a separate XD directory with `--eos=adiabatic`; preserve the validated table-EOS binary.

This is a controlled *local code* EOS/opacity comparison. It is closer to [Mayer et al. §5](https://arxiv.org/html/2510.12620#S5) than the table run, but still uses Athena++ Cartesian Jeans AMR and its own ambient pressure implementation rather than AREPO's moving mesh, mass refinement, and published background treatment. Figure 7 points are approximate read-offs, not a published numerical data table.
