# Mayer §5 ideal-EOS collapse from cycle 0 with one binary

## Initial-condition sources and choices

[Mayer et al. (2025), §5.1](https://arxiv.org/html/2510.12620#S5) specifies a uniform nonrotating, unmagnetized sphere of 1 M☉ and radius 3000 au, initial 14 K, μ=2.381, γ=5/3, fixed κP=κR=1 cm² g^-1, and a 12000 au box with periodic hydro but isolated gravity. It says the background pressure is raised and its initial temperature fixed, and identifies this as the nonrotating, unmagnetized version of the precursor's initial conditions. The cited [precursor, §3.1](https://arxiv.org/html/2410.07016#S3) gives a background density lower by factor 30 and says it starts in pressure equilibrium with the core. **Inference from the two papers:** set ρambient=ρcore/30 and Pambient=Pcore. With the ideal gas law this sets the background's initial, fixed temperature to 420 K. The new [input](wor92_mayer5_reference_c0_20261110.in) uses those values and an unsmoothed boundary (`transition_width=0`). The previous c0→10 control 339293 used ρambient=ρcore/100, Pambient=Pcore/100 (14 K background); its queued long job 339296 was cancelled before start when this source detail was found.

The initial sphere's analytic density is 5.2515854e-18 g cm^-3. The mesh is Cartesian Jeans AMR with N_J=32, while Mayer uses AREPO's moving mesh and a mass target of 3.33e-7 M☉; those spatial discretizations remain different. The paper's treatment of background radiation is not specified numerically; this input retains the established fixed-background radiation choice. The target mass parameter is recorded in the input but inactive under Jeans-only refinement. The comparison target is the paper's **global-timestep** variant.
