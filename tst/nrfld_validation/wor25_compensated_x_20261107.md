# WOR-25: compensated FGMRES restart update trial

This isolated branch starts from validated commit `2ecbea05f13e29fcfa4905e1cbedd2342059be14`. The local build uses `nrfld_diff_amr_interface`, MPI, `NRMGFLD`, Cartesian geometry, and HDF5 double output. The test-only binary SHA-256 is `90489fbefee919580859cdc19e92321ec078bbb3d4ce306c559460415e0f6dfb`. No XD2000 job, other worktree, or main merge was used.

The [test-only patch](wor25_compensated_x_test_only.patch) keeps a low-part vector for the FGMRES solution across *all* restarts. Each restart sums its Arnoldi corrections in `long double`, rounds the represented solution once to `Real`, and stores the discarded low part for the next restart. The matvec and returned Newton correction still use the rounded `Real` vector. This extends the earlier within-restart long-double sum trial without changing the operator or tolerance. The patch SHA-256 is `6203c5f5573408ac4598a3c5debc7e527491bd4d483c19d4f66a04f0169c3a92` and applies cleanly to the branch base. The patch was removed from tracked solver source after the failed trial.

Both runs used the same binary and [`testc_threelevel_shifted_20261107.in`](testc_threelevel_shifted_20261107.in), input SHA-256 `c1ffedae69f670d6f17740805077b6741c7cefdaf2baf4639cc7ab5f1fa38a74`: coupled gas/radiation, variable limiter, centered conservative face ON, 1 MPI rank, two steps, strict FGMRES true-residual target `1e-8`. The only experimental difference was `ATHENA_NRFLD_FGMRES_COMPENSATED_X_TRIAL=1` versus unset. The comparison is within this binary; earlier binary trajectories are not assumed identical.

The compensated variant changed the rounded iterate and made the true-residual floor *higher* in this trajectory. Its smaller projected residual still did not correspond to a representable `Real` correction satisfying the strict target. This result, the earlier one-restart long-double-sum failure, and the measured `A(update gap)` close to the true residual show that rearranging these sums alone is not a reliable remedy. They do not prove that every nearby representable vector fails; a wider precision representation or a rigorously bounded inexact-Newton acceptance remains a separate question.
