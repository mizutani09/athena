## WOR-25: MG 単独失敗の修正候補

保存的 Test C、fixed limiter、shifted AMR、強拡散 `q=1e7`、1 rank の同一入力で候補を比較した。既定 MG 単独は最初の Newton で `backtracking_exhausted`。返却補正は体積平均が約 `-20.56` で全セルの放射エネルギーを負にする。FGMRES 対照は補正平均約 `-7.9e-6`、9+9 線形反復、Newton 2 回で収束した。MG の取得直後に見える相対残差が約 `5.5e-11` でも、粗細面 ghost 更新後には `1.64e-2`、fine sweeps 後にも `8.67e-3` である。強拡散の定数モードと粗細面の境界更新が両方効いている。

| 試した候補 | 結果 | 判定 |
| --- | --- | --- |
| MeshBlock 内残差最小化 | 各補正係数 β は全て 1、Newton 失敗 | 取り消し |
| AMR tangent 補間、対称 RBGS | 単独・組み合わせとも Newton 失敗 | 取り消し |
| 粗補正係数 0.25 / 0.5 / 0.75 / 1.25 | 全件失敗。0.25 の初回 V-cycle 残差係数 3.21、既定約 0.12 より悪化 | 取り消し |
| coarse solver legacy、constant prolongation、FMG、double Jacobi | 全件 Newton 失敗 | 取り消し |
| 周期・純放射の体積平均方程式への定数モード射影 | 平均 `-20.56` を右辺平均約 `1.14e-11` に直したが、shifted は Newton 失敗。fine sweeps を 64/256 に増やしても返却残差は `5.91e-3` / `3.92e-3` | 試験コードを取り消し |

この失敗は `A_H` と `R A_h P` の不一致だけで説明できない。定数モード射影は positivity を回復したが、粗細面に残る誤差が Newton residual を悪化させた。保存的演算子のこの強拡散条件では、現状の FGMRES を使うのが検証済み経路である。

### 実補正の最長波長成分

返却補正の体積平均だけでは非定数の低周波誤差を区別できないため、既存の opt-in `handoff_diagnostics` に x1 全域の第1 Fourier 調和の振幅 `2|∫δe^{-2πix/L}dV|/V` と、RHS・残差の同振幅を追加した。これは**実際の MeshBlock 補正を境界同期後に測る投影**であり、AMR composite operator の固有モードを主張しない。診断ソース SHA-256 `08ffe0da7d6b2108c1bbea894aa2c945e686782b54b5631103c3fb103ede54a5`、現行 matvec を含む隔離バイナリ SHA-256 `6ec1605edef342be76656101904865dc5da106d011cfb7aa5b5039de36a8fc52`。同じ fixed limiter・強拡散 `q=1e7` の Test C で uniform、aligned AMR、shifted AMR を比較した。

| 配置・初回補正 | MG境界後の補正平均 | MGの最長波長振幅 / FGMRESの同振幅 | MG境界後の最長波長残差 | 結果 |
| --- | ---: | ---: | ---: | --- |
| uniform | `-8.72e-14` | `0.0194287865 / 0.0194287867` | `3.68e-9` | MG/FGMRESともNewton 2回でPASS |
| aligned AMR | `+0.00142414` | `0.0194309889 / 0.0194307113` | `1.39e-4` | MGはNewton 5回、FGMRESは2回でPASS |

shifted のMGは fine sweeps 後も最長波長振幅 `0.0182297` で、FGMRESより **6.18%小さい**。最長波長残差は `40.37`、FGMRESの `1.18e-5` の約340万倍である。したがって過大な定数成分だけでなく、非定数の長波長補正もずれている。aligned の同振幅差は約 `1.43e-5`、uniform は `8.5e-9` に留まる。ただしこの投影は誤差の原因を粗格子のどの係数/伝達に帰属するかまでは示さない。単に `A_H` と `R A_h P` の不一致値から失敗を判定せず、実際の返却補正・残差・Newton成否との対応として扱う。

shifted は1/2 rankのMG失敗とFGMRES `9+9`、最長波長指標を再現。FGMRESの1/2 rank最終HDFは全数値配列が完全一致し、診断ON/OFFも同一バイナリで全数値配列が完全一致した。uniform/ aligned / shifted の各入力SHA-256、Git/バイナリhash、全反復・true residual、最長波長を含む全handoff履歴、単精度HDFからのEr体積積分、時間/RSS、PASS/FAILはJSONの `wor25_first_harmonic_handoff_audit` に保存した。診断ON/OFFは異なる並列負荷で実行したため壁時計差を性能比較に使わない。診断は追加の全域集計を伴い、既定OFFを維持する。MGの粗格子演算子は変更せず、shifted強拡散はFGMRESを検証済み経路とする。

厳格な `fgmres_threshold=1e-10` は第1線形 solve で到達しても第2 solve が true residual 約 `1.13e-9～1.17e-9` に停滞した。restart 20/40、batched reductions 無効、basis 再利用無効、最大 80/400 反復でも解消しない。停止規則だけを緩める根拠はない。

### FGMRES matvec の差分形による精度改善

保存的演算子の強拡散時、FGMRES matvec が大きな対角項と隣接項を個別に足すため桁落ちする。保存された係数行を変えずに、各面の `D_face (u_neighbor-u_center)` と係数行和を `long double` で蓄積する最小修正を試した。元の shifted Test C `q=1e7`、厳格 `fgmres_threshold=1e-10`、restart 40・最大 400 反復の第2 solve の**明示 true residual** は次の通り。

| matvec | MG V-cycle/前処理 | 第2 solve の 400 反復後 true residual | 目標達成 |
| --- | ---: | ---: | --- |
| 既定の個別和 | 1 | `1.168e-9` | FAIL |
| 差分形 `long double` | 1 | `4.891e-10` | FAIL |
| 既定の個別和 | 2 | `2.724e-10` | FAIL |
| 差分形 `long double` | 2 | `1.630e-10` | FAIL |

差分形・2 V-cycle で restart を 80 にしても `1.630e-10` のままだった。丸め誤差床を下げたが、厳格閾値を解決したとは扱わない。通常 `1e-8` 閾値の保存的 Test C fixed/shifted は 1/2 rank とも `9+9`、変係数 shifted は各 20 solve・総 202 反復で従来と同じ。両条件の最終単精度 HDF は変更前と完全一致し、1/2 rank の FGMRES 演算子加法性/斉次性誤差は `2.47e-16 / 5.57e-16`。43-leaf collapse restart の 1/2 rank・2 OpenMP thread も `14+14` で Newton 収束、粗細面 9 組の最大相対積分面項不一致 `1.71e-7 / 1.13e-7`（PASS）。従来の最終 double-HDF との差は prim/fld 相対 L1 で 1 rank `1.02e-13 / 2.53e-13`、2 rank `1.44e-13 / 3.59e-13`。通常試験の時間/RSS と保存診断も JSON の `wor25_stable_matvec_trial` に記録した。確認済みの数値精度改善としてこの小修正を残すが、MG 単独失敗と厳格残差床は WOR-25 未解決のままである。

最後に隔離ビルドだけで厳格失敗時の返却補正を `PrintHandoffDiagnostic()` に渡し、FGMRES の残差再計算とは独立に検算した。2 V-cycle・400 反復の第2 solve は、1/2 rank の FGMRES true residual `1.630e-10 / 1.631e-10` に対し、`long double` 差分形で再評価した全域相対残差 `1.447e-10 / 1.442e-10`。RHS RMS は `7.84e-8 / 7.86e-8`、残差 RMS は両 rank 約 `1.13e-17`。内域、同 level 面、粗細面の独立再評価はどれも `~1e-10` で、粗細面だけに誤差が集中していない。通常の double 行和で再評価すると相対残差は `3.45e-10 / 3.43e-10` とさらに大きい。真残差報告だけの誤判定ではなく、状態・RHS の絶対丸め幅に近い床を確認した。停止閾値を見かけ上緩めたり失敗を PASS に変えたりせず、隔離用の失敗時出力コードは追跡ソースに残さない。2 run の入力/hash・時間/RSS・領域別指標・FAIL は JSON の `wor25_strict_residual_independent_audit` に記録した。

### 前処理 V-cycle 回数の追加対照

同じ保存的 shifted AMR の FGMRES 前処理を `fgmres_mg_vcycles=1/2/3` で比較した。fixed limiter、`q=1e7` の 1 rank では総反復数が `18/15/13`、壁時計時間が `2.11/2.13/2.11 s`。1/2 rank 対照では 1/2 V-cycle とも最終 HDF が一致し、2 rank の実行時間は `1.33/1.36 s` だった。変係数 limiter の shifted AMR では 20 線形 solve の総反復数が `202/160/140`、時間が `3.20/3.80/4.29 s`。全件 Newton 収束、各 solve の明示 true residual は `1e-8` 以下で、同一条件内の最終 HDF は全数値配列が一致した。fixed では Er の HDF 体積積分を double で蓄積すると初期と最終が同じ `0.015781657421030104`、Er 最小値は `1.01002538`。変係数ケースにはガス・放射源があるため、この Er 単独積分を保存判定には使わない。追加 V-cycle は Krylov 反復を減らすが時間の改善を示さず、既定値 1 を維持する。入力 hash、全反復・残差、rank ごとの時間と RSS は JSON にある。

## WOR-23: mixed-frame coupled global Jv

従来の coupled 診断が拒否していた mixed-frame drift について、凍結済み面係数 `q·v` の方向微分をガス・放射の解析 Jv に加えた。実 Newton 方向では radiation ghost 同期後に drift の空間結合を含むガス行を消去する。診断用入力では `include_mixed_frame_terms=true` **かつ** `mixed_frame_transport=true` とし、実際に drift が有効なことを確認した。前者だけでは drift は無効になる。

Mach 5、user x1 / 周期横方向、静的 AMR 9 leaf、fixed limiter、1/2 MPI rank で、滑らかな独立2変数方向と実 Newton 方向を有限差分した。粗細面 320 セルの実 Newton Schur 相対 L2 誤差は `h=1e-2` で `3.13e-4`、`h=1e-3` で `3.10e-5`。滑らかな方向の粗細面と物理境界もほぼ一次で減った。解析的な full-system→assembled-Schur 差は粗細面で `4.15e-12`。実 Newton 方向は `h<=1e-4` で丸め誤差に支配され、特に物理境界の有限差分は単調減少しないため、その範囲を PASS 根拠に使わない。

各 rank は Newton 5 回、FGMRES `7+7+6+6+6` 回で収束し、各 solve の true residual は `1e-8` 以下。診断 ON/OFF と 1/2 rank の最終 double-HDF 全数値配列は完全一致。drift 有効/無効の最終 uov は相対 L1 `2.80e-6` 異なり、同じ計算を誤って比較したわけではない。変更後も drift 無効 Mach 5 と Test C fixed/variable shifted の診断を再実行し、最終 HDF が従来結果と一致した。これは診断専用変更であり、mixed-frame のあらゆる非線形状態や変係数 limiter まで保証しない。

速度を元入力の 2 倍・5 倍にし、両方の mixed-frame スイッチを有効のまま再測定した。粗細面の実 Newton Schur FD 相対 L2 は、2 倍速度で `h=1e-2/1e-3` に対し `4.50e-4/4.58e-5`、5 倍速度で `9.94e-5/1.11e-5`。解析 Schur 差はそれぞれ `5.39e-12/3.78e-12`。小さい `h` では物理境界などで丸め誤差が再び優勢になる。2 倍速度は Newton 5 回・FGMRES 合計 35 回、5 倍速度は Newton 4 回・FGMRES 合計 24 回で収束した。5 倍速度の診断 ON/OFF と 1/2 rank の最終 prim/uov HDF 全数値配列は完全一致し、FGMRES 履歴も rank 間で丸め差を除いて同じ。最終 ρ/圧力/Er の最小値は `5.46e-13/4.54e-3/7.57e-7` で正だった。これも固定 limiter の短時間静的 AMR 試験であり、変係数 mixed-frame の証明には拡張しない。

### coupled variable-limiter collapse の粗細面 Jv 追試

collapse 縮小入力（16³ root、8³ MeshBlock、静的粗細面 15 leaf、周期境界、MHD、自己重力）で、`include_mixed_frame_terms=true` と `mixed_frame_transport=true` を同時に設定した。collapse の保存的経路を許可する変更は隔離ビルドのみに置き、追跡ソースの用途 guard は維持した。

`8763a6139a6fe5fe56d988ebd53d80063f090320` で coupled 診断の基準状態と摂動状態の両方に共有面モーメント同期を追加した。隔離バイナリ SHA-256 は `4caa33aacaafcdd8fd952bff20318075a0df2a6c13a31bd839eaa2930835c7c1`。下表は修正後の `h=1e-5`、粗細面 1736 セルの Schur Jv 相対 L2 である。

| 条件 | MPI rank | smooth | 実 Newton 方向 | FGMRES 反復・真残差 | 判定 |
| --- | ---: | ---: | ---: | ---: | --- |
| 共有面係数、変係数 limiter・mixed-frame transport | 1/2 | `3.02e-10` | `3.10e-9` | `14 / 2.97e-9` | PASS |

別候補として共有面係数を無効にすると Jv は `3.24e-9`、FGMRES は 14→12 反復へ改善したが、**保存的演算子として失格**だった。`ATHENA_NRFLD_INTERFACE_LEDGER=1` の 3 つの実粗細面で、対向する積分面項の最大相対不一致は共有ありで 1 rank `8.33e-8`、2 rank `4.89e-8`、共有なしで 1 rank `0.1884047`、2 rank `0.1884046`。`collapse_interface_ledger.py --require-conservation` は許容 `1e-6` で前者を PASS、後者を FAIL と判定した。共有なしでもρ/圧力/Er は正、質量相対変化は両設定とも `8.0031e-9` だったが、Er 単独の体積積分には背景源とガス交換があるため保存判定に使わない。Test C の弱・強密度対照は共有なしでも全域 Er 保存を通したが、collapse の面別診断で明確に失敗したため候補を取り消した。

tangential face reconstruction を無効にした場合の面別不一致は 1/2 rank で `8.35e-8/5.57e-8` と小さく、収束もした。ただし短い 1 step の反復差だけでは既存の空間精度上の利点を覆せず、既定設定は変えない。大規模 collapse の用途 guard、長時間 regrid と閉じた保存予算の未検証は残る。各入力 SHA-256、Git・バイナリ hash、反復履歴、真残差、実行時間、最大 RSS、面別不一致、PASS/FAIL は JSON と入力アーカイブに記録した。

## WOR-24: 保存的 collapse の縮小試験

用途 guard の緩和は `/tmp/wor25_23_24_resolution_collapse_trial_build` だけで試し、追跡ソースには残していない。既定サイズの入力は約 20 GB RSS に達したので停止した。代わりに 16³ root、8³ MeshBlock、15 leaf（level 0 が7、level 1 が8）の静的粗細面を用いた。coupled variable limiter、mixed-frame transport、MHD、自己重力を保った。

MG 単独は Newton backtracking で失敗した。FGMRES は保存的経路で 1/2 rank とも 1 cycle 14 反復、true residual 約 `2.97e-9` で収束し、連続 2 cycle は `14+14` 反復。旧 AMR 演算子の同一入力は合計 127 反復だった。連続 2 cycle の質量相対変化は保存的・旧演算子とも約 `1.553e-8`、保存的経路の放射エネルギー体積積分は `-2.04e-4` 変化。ρ、圧力、Er は正である。これは hydro、重力、背景熱源を含む閉じた保存予算ではない。

同一 cycle-1 checkpoint からの restart は 1/2 rank 同士で相対 L1 約 `1e-15` に一致した。一方、連続計算と restart の cycle-2 最終値は prim `1.36e-7`、fld `1.01e-8` の相対 L1 差がある。旧演算子でもほぼ同じ差が出た。cycle-1 の再起動直後に比べると、ρ・圧力・速度・Er は一致するが、自己重力の `phi` と `defect-phi` は変わる。これが次 step の hydro へ伝播している可能性があり、保存的 FLD 固有の restart 修正とは判定しない。adaptive regrid、閉じた保存予算、実規模精度、重力 restart の段階差が残るので collapse の用途 guard は維持する。

### restart 差の重力依存性

非均一な collapse 初期分布と粗細面を保ち、**隔離ビルド内だけ** `SetGravitationalConstant(gravity_code)` に試験係数を掛けた。その他の入力は同じで、連続 2 cycle とその cycle-1 checkpoint からの restart を比較した。

| 重力係数 | 最終 prim 相対 L1 | 速度の最大絶対差 |
| ---: | ---: | ---: |
| `1e-30` | `2.78e-14` | `1.22e-16` |
| `1e-3` | `2.68e-10` | `2.85e-9` |
| `0.1` | `2.45e-8` | `2.85e-7` |
| `1.0` | `1.36e-7` | `2.84e-6` |

速度差が重力係数にほぼ比例し、重力を実質ゼロにすると restart 差が丸め精度まで消えた。`MeshBlock::GetBlockSizeInBytes()` と restart writer は重力 `phi` を保存せず、`Mesh::Initialize()` は restart 時にも重力を再計算する。restart 直後の放射・流体状態が一致して `phi` だけが先に異なる観測とも整合する。これは原因を重力状態の再構築と時間段階の整合へ絞るが、どの段階の `phi` を checkpoint に対応させるべきかは未検証である。試験係数のコードは追跡ブランチに残していない。

### 重力 restart 時点の修正候補

自己重力状態の時点を揃える二つの小さな候補を隔離ビルドで試した。第一は各 step の `LoadBalancingAndAdaptiveMeshRefinement()` 直後に `pmgrd->Solve(1)` を追加するもの、第二は `Mesh::Initialize()` の最初の重力 solve を hydro 境界・primitive 初期化の後へ移すもの。静的粗細面の連続 2 cycle と cycle-1 checkpoint からの restart を同一バイナリで比較した。対照の最終 prim/fld 相対 L1 差は `1.361488e-7/1.010520e-8`、step 後再計算は `1.361482e-7/1.010503e-8`、初期化後移動は対照と同じだった。全件 Newton 収束、FGMRES は連続 `14+14` 回、restart `14` 回、各 solve の true residual は `3e-9` 以下。追加 solve は差を解消せず、境界初期化順序だけでも説明できない。二つの試験コードはいずれも追跡ブランチへ採用しない。元の重力状態・境界条件・restart 構築をさらに調べる必要がある。入力 hash、checkpoint hash、隔離バイナリ hash、時間・RSS は JSON に記録した。

さらに multipole 境界の原点を明示的に `(0,0,0)` に固定した FMG、および FMG 重力閾値を `1e-12` にした対照も、最終 prim/fld の連続対 restart 差を約 `1.36e-7/1.01e-8` から改善しなかった。重力 `mgmode=MGI` へ切り替えると一見この差は `3e-14` 程度になるが、**最終 `phi` が全セルでゼロ**だった。重力 V-cycle は初回から残差を約 4.8 倍に増やし、発散検出が初期解へ戻していた。MGI の restart 一致は重力を実質無効にした偽の改善であり、閾値 `0`、`1e-8`、`1e-12` の全てを棄却する。これは FLD の Newton/FGMRES が収束したことだけでは重力の物理的妥当性を保証できない例でもある。FMG の既定値と collapse 用途 guard を維持する。

同じ 16³ root と 8³ MeshBlock の入力から `refinement=none` にした uniform FMG 対照では、連続 2 cycle と cycle-1 checkpoint restart の最終 prim/fld 相対 L1 差が `1.68e-19/9.01e-28` だった。FGMRES の全 true residual は `1e-8` 以下。静的 AMR と uniform の対比から、未解決差は一般的な hydro/FLD restart だけでは再現せず、AMR 階層を持つ重力 MG に依存する。粗細面の重力境界・root/octet 受け渡しと FMG 再初期化を次に調べる。

さらに FMG solve の前後に隔離ビルドで密度・`phi` の active-cell 和を記録した。15 block の cycle-1 checkpoint 時点で、連続実行の stage-2 solve に入る密度和と restart 初期化 solve に入る密度和はどちらも `3089.74545552749623`。しかし返却 `phi` 和は連続 `-13627.0395735188013`、restart `-13631.8910649735808` だった。追加の配列ハッシュ測定では、全 63 個の gravity MG source 配列が ghost を含めて一致し、重力定数、multipole 原点・先頭係数、active 密度配列ハッシュも一致した。差はこの入力配列以外の FMG solve 状態にある。追跡ソースへ計測コードは入れていない。

### 実際の adaptive refinement

初期の粗細面を保持しつつ refinement を起こすため、局所 Jeans 指標を調べて `refinement=adaptive`、`refinement_mode=jeans`、`N_J=7.61660` を選んだ。初期と cycle 1 は level 0 が7、level 1 が8 の 15 leaf。cycle 2 に level 1 が64 の topology へ変わり、cycle 3 まで保存的経路の 1/2 rank がともに完走した。FGMRES は各 solve で真残差目標を満たし、最終 prim/uov の rank 間相対 L1 は `1.95e-15` / `4.07e-15`。同じ cycle-1 checkpoint からの 1/2 rank restart も同じ topology で完走した。restart 同士は一致するが、連続計算との差は prim `1.13e-7`、fld `2.64e-9` で重力に由来する差が残る。

初期から cycle 3 の質量体積積分の相対変化は保存的経路も旧演算子対照も約 `1.107e-7` だった。ρ・圧力・Er は正。**この連続試験は refinement 一回**であり、derefine、閉じた全エネルギー予算、大規模 AMR 精度は検証していない。粗細面を失う一様 refinement の入力は対照に留め、PASS の根拠には使わない。

別の診断として、cycle-2 の level 1:64 checkpoint を読み、`problem/N_J=1` と `mesh/derefine_count=1` を指定して level 0:8 へ derefine させた。保存的経路は 1/2 rank とも完走し、最終 prim/uov の rank 間相対 L1 は `1.68e-16` / `1.04e-16`、ρ・圧力・Er は正だった。線形 solve の明示 true residual は全件 `1e-8` 以下。旧演算子対照も同じ topology で完走し、質量体積積分の変化はほぼ一致した。この入力は **checkpoint 後に refinement 判定を変えた短い診断**であり、自然な collapse の長時間 derefine や閉じたエネルギー予算は保証しない。

### 部分 refinement 後の Jv と MPI 重力差

従来の自然な adaptive 試験では 15 leaf が一度に level 1:64 へ揃い、再配置後に粗細面がなくなった。そこで隔離ビルドで refinement 判定値を観測し、`N_J=7.616410190`、`nlim=6` を選んだ。6 cycle 後に 15 leaf（level 0:7 / level 1:8）から 43 leaf（level 0:3 / level 1:40）へ部分 refinement した。1/2 rank の最終 topology は同じ。再配置直後の **同一 1-rank checkpoint**（SHA-256 `42416ee70c7cc08b4065e33903fb64239d8389ac7dd356fa7ce631641bfcadb1`）を 1/2 rank で読み、`problem/N_J=1` として追加 refinement を止め、1 cycle の coupled variable-limiter + mixed-frame transport を解いた。この threshold 変更は診断目的であり、自然な長時間 collapse の設定ではない。

新しい粗細面 5120 セルの実 Newton Schur Jv 相対 L2（`h=1e-5`）は 1 rank `7.64e-9`、2 rank `7.92e-9`。ghost 接線差は `約1.5e-10`、解析 Schur 差は `約8e-15`。Newton は各 rank 2 回、FGMRES は `14+14` 回で、明示 true residual は 1 rank `3.33e-9/7.86e-9`、2 rank `3.33e-9/7.86e-9`。ρ・圧力・Er は正。診断 ON/OFF の 2 rank 最終 HDF は全数値配列が完全一致し、粗細面 9 組の対向積分面項の最大相対不一致は 1 rank `2.05e-7`、2 rank `1.56e-7`（許容 `1e-6` で PASS）。2 rank の MPI stdout は途中で文字が交錯したため、再実行では `mpirun --output-filename` の rank 別ログを使った。面別 ledger スクリプトは不完全な行を明示的に拒否するよう修正した。

ただしこの配置は **WOR-24 の新しい MPI 重力再現性 FAIL** を露呈した。連続実行の 1/2 rank は cycle 0–5 に同一 topology で `phi` が相対 L1 `4e-16` 以下に一致したが、cycle 6 の部分 refinement 直後は密度が相対 L1 `2.24e-16` で一致したまま `phi` が `2.27e-4`、最大絶対差 `0.00642` に開いた。放射 `Er` は `7.66e-13` で一致する。checkpoint からの 1 step 再開でも最終 `phi` は rank 間 `2.27e-4`、prim 全体 `1.10e-4`、速度成分 `4e-5～6e-5`、Er `8.3e-9` の相対 L1 差が残る。したがって最初の差は FLD の Jv や checkpoint 読み込み後の状態ではなく、**部分 refinement 後の重力 FMG 解**で発生する。重力 FMG 色位相固定 + restart 初期追加 solve の併用でも `phi` 差は `2.27e-4` のまま。重力閾値 `1e-12` でも `2.27e-4`。FMG 最終 defect は rank 1 `1.9738e-8`、rank 2 `1.9769e-8` と異なった。既存 opt-in の restart 一致は 15/64 leaf の条件に限ると明記し、この部分配置へ一般化しない。

色位相固定の連続 1/2 rank 試験は同じ閾値で **64 leaf へ全域 refinement** し、rank 間一致した。topology が異なるため 43 leaf の改善証拠とは扱わない。部分配置の入力、checkpoint hash、各 run の Git/binary hash、反復・真残差、質量体積積分、実行時間/RSS、面別 ledger と PASS/FAIL は JSON と入力アーカイブにある。次は重力 MG の root/octet source・境界・色位相を 43 leaf の同一密度で 1/2 rank ごとに比較する。用途 guard は維持し、WOR-24 は未解決のままとする。

### 部分 refinement の重力 MPI 差を解消する最小修正

同一 checkpoint の 1/2 rank で、最初の重力 FMG に入る直前の root/octet ソース配列はハッシュまで一致した。FMG level 0–2 の解は丸め精度で一致し、level 3、すなわち root/octet から MeshBlock へ渡る最初の level で差が現れた。`TransferFromRootToBlocks()` が呼ぶ `SetOctetBoundariesBeforeTransfer()` は各 rank のローカル MeshBlock から親 octet を列挙していたため、同じ 5 octet を複製して持つ rank ごとに境界更新済み octet が異なった。初回受け渡し時に、1 rank と 2 rank の MeshBlock `gid=21,23` ではソースの和が同じなのに補正の和がそれぞれ `0.528, 0.144` 異なった。多重極原点の固定と、最初の多重極係数を 1 rank の値へ強制する試験でもこの差は消えなかった。周期重力境界に変える試験は差を消したが、同時に Poisson ソースの平均を差し引くため、物理的に同じ問題の修正候補には使えない。

共有 MG の受け渡し前に **全 octet の境界を各 rank で更新**する最小修正を専用ブランチへ適用した。隔離された通常ビルド（SHA-256 `6298a6e45cb1f151deafdea0795ea11a7b3b3f3269e5e9770a6b54d026ff75be`）で、元の 43 leaf 入力の連続 6 cycle は 1/2 rank とも同じ topology を生成し、cycle 6 の `phi` 相対 L1 差は修正前 `2.27e-4` から `5.24e-16` に低下した。同じ 1-rank checkpoint からの 1 step 再開では最終 `phi` 差 `4.84e-16`、ρ 差 0、Er 差 `1.24e-12`。15 leaf 静的配置は `phi`/ρ 差 0、64 leaf 全域 refinement は `phi` 差 `3.86e-16`、両配置の Er 差は `2e-15` 以下だった。全 run は Newton 収束、FGMRES は 43 leaf 再開で 1/2 rank とも `14+14` 回、明示 true residual は各 solve `1e-8` 以下。43 leaf の粗細面 5120 セルの実 Newton Schur Jv は `h=1e-5` で 1 rank `7.64e-9`、2 rank `7.99e-9`。9 組の対向積分面項の最大相対不一致は 1 rank `2.05e-7`、2 rank `2.42e-7`（許容 `1e-6`、PASS）。入力と checkpoint、binary/Git hash、反復履歴、時間/RSS、比較量は JSON に追記する。

### octet の物理境界に渡す中心値を先に確定する修正

22 leaf の OpenMP 2 thread 実行を同条件で繰り返すと HDF と反復履歴は完全一致した。1/2 thread の初回 gravity 出力は `phi` 相対 L1 `5.32e-7` で異なり、初期密度と Er は一致した。multigrid 配列の byte hash を FMG ごとに追うと、root/octet は level 2 まで一致し、level 2→3 の受け渡し中に octet 0 の境界だけが分岐、その子 `gid=2–7` に伝わった。`SetOctetBoundariesBeforeTransfer()` は `ApplyPhysicalBoundariesOctet(cbuf,...)` を呼んだ後で `ProlongateOctetBoundaries()` に `cbuf` 中心値を設定させていた。multipole 境界は中心値を読むため、前回の作業バッファの値で境界 ghost を計算していた。全 cbuf をゼロにする診断でも thread 差は消えたが、正しい中心値を使う結果から `phi` が相対 L1 `7.50e-5` ずれるため採用しない。多重極係数集計、座標構築、MeshBlock task list、root/block 転送を個別に逐次化する診断は差を消せなかった。全 MG の逐次化は差を消したが広すぎるため採用しない。

### collapse の部分配置移動と往復 regrid

対称な Jeans 閾値だけでは別の 43-leaf 配置へ移せないため、隔離 pgen の refinement tagger に二つの octet を交換する試験条件を追加した。元の cycle-6 checkpoint（SHA-256 `42416ee70c7cc08b4065e33903fb64239d8389ac7dd356fa7ce631641bfcadb1`）を共通に用い、`mesh/derefine_count=1`、`N_J=7.6160`、1/2 MPI rank・各 2 OpenMP thread で再開した。単発移動パッチと往復パッチは入力アーカイブの `trials/collapse_single_shift_test_only.patch`、`trials/collapse_oscillating_shift_test_only.patch` に保存した。本番 pgen と collapse 用途 guard は変更していない。最初の試走では HDF の相対 level 0/1 を `MeshBlock::loc.level` に誤用して配置が変わらなかった。実際の callback では level 1/2 と確認してパッチを修正し、以下は修正後の全 run である。

単発移動では 43 leaf のまま 7 MeshBlock 作成・7 破棄、出力上は 9 leaf が入れ替わった。1/2 rank とも 3 step・6 線形 solve の総 FGMRES 反復 79、全 true residual `1e-8` 未満で Newton 収束。粗細面 23 面対の最大相対積分面項不一致は `1.71e-7 / 1.39e-7`（PASS）。新配置の粗細面 3072 セルで coupled Newton Jv `rel2`（`h=1e-5`）は `1.77e-9 / 1.71e-9`。各出力の prim/fld double-HDF の rank 間相対 L1 は最大 `6.30e-14 / 1.55e-13`。

往復条件では cycle 7/9/11 に交換を繰り返し、43 leaf のまま合計 21 MeshBlock 作成・21 破棄、HDF 上は 9 leaf の入れ替えを 3 回確認した。1/2 rank とも 7 step・15 線形 solve の総 FGMRES 反復 195、最大 true residual `8.90e-9`、Newton は全件収束。粗細面 51 面対の最大相対積分面項不一致は `1.71e-7 / 1.39e-7`（PASS）。新配置の粗細面 Newton Jv `rel2`（`h=1e-5`）は各回約 `1.25e-9～1.80e-9`、smooth 方向は `3.20e-10` 以下。全出力の prim/fld double-HDF の rank 間相対 L1 は最大 `3.01e-13 / 6.43e-13`。最終 ρ・圧力・Er 最小値は `0.05184 / 0.02534 / 2.91e-10` で正。質量体積積分の初期→最終相対変化は両 rank `1.237e-7`、暗黙段階の energy ledger 最大 absolute relative balance `2.75e-10 / 4.42e-10`。背景処理・hydro・重力を含む閉じたエネルギー予算ではないため、質量・energy ledger だけで実規模保存性を証明しない。4 run と失敗した topology 試走の入力/checkpoint・Git/バイナリ hash、全反復履歴、Jv、保存量、時間/RSS、PASS/FAIL は JSON の `collapse_shifted_partial_regrid` に記録した。

### 往復 regrid 後の restart

上記の 43-leaf 往復条件で、cycle 7/9 の二度の octet 交換を経た cycle-10 checkpoint（SHA-256 `db5093bcbd632744ce8b8433b4fc918f3308c80c001ed5adb21552`）から cycle 13 まで再開した。1 rank の checkpoint を 1/2 MPI rank・各 2 OpenMP thread で読み、cycle 11 の三度目の交換（7 MeshBlock 作成・7 破棄）も実行。隔離バイナリは往復試験と同じ SHA-256 `0f649c02137232c0a862514e6532286a1c959193325e89dc84821d6fb7882de2`。`mesh/derefine_count=1`、`problem/N_J=7.6160`、mixed-frame・変係数 limiter・MHD・自己重力・coupled FLD は維持した。各 restart は 7 線形 solve・FGMRES 総反復 91、全 true residual `<1e-8`、全 Newton 収束。23 粗細面対の最大相対面項不一致は `1.62e-7 / 2.13e-7`（PASS）、暗黙 energy ledger の最大 absolute relative balance は `2.68e-10 / 4.30e-10`。cycle 11→13 の質量積分相対変化は両 rank 約 `2.94e-8`。最終 ρ/圧力/Er は正。

restart した 1/2 rank 同士の最終 prim/fld double-HDF 相対 L1 は `7.35e-14 / 1.81e-13`、topology も一致した。一方、同じ設定の連続計算と restart では最終 prim/fld に `2.030e-9 / 2.411e-11` の差が残る。checkpoint 直後の最初の出力でも prim `7.66e-10` の差があり、その後の step に伝播した。既存の重力 opt-in `reset_fmg_color_each_solve=true` と `repeat_initial_fmg_after_restart=true` を**連続計算と restart の両方**へ適用した独立対照では、1 rank の連続 run は 21 MeshBlock 作成・21 破棄、総 195 反復・全 Newton 収束、51 面対最大不一致 `1.69e-7`（PASS）。同じ opt-in で cycle-10 checkpoint から再開した 1/2 rank は総 91 反復ずつ、23 面対最大 `1.85e-7 / 1.93e-7`（PASS）。しかし連続対 restart の最終 prim/fld 差は `2.025e-9 / 2.347e-11` と実質不変だった。この配置では opt-in 二つは restart 差の解決策として採用しない。既定 false、用途 guard と追跡ソースは変更しない。

初期化で差が生じる場所を調べるため、同じ cycle-10 checkpoint を読んで `time/nlim=10` とし、時間 step を一度も進めずに HDF を出す対照も行った。連続計算の cycle-10 出力と再初期化直後は時刻・cycle・topology が一致し、ρ・圧力・速度・tracer・Er は**全要素完全一致**。既定設定では `phi` だけ相対 L1 `2.441e-8`、最大絶対差 `4.646e-7`、`defect-phi` 相対 L1 `1.395e-5` の差が生じた。重力 opt-in 二つを両側で有効にすると、初期化直後の `phi` 差は `5.055e-12`、最大絶対差 `9.620e-11` まで縮む。しかし時間 step を進めた後の prim 差は前段の通り約 `2.025e-9` のまま。**初期 `phi` の差が存在することと、その差だけで後段の差を説明できることは別**である。opt-in は初期重力場を改善するが、この動的配置の連続対 restart の解決とは判定しない。初期化のみの 2 run は暗黙 step がないので面・energy ledger は対象外。コマンド、checkpoint/binary hash、時間/RSS、各場差と PASS/FAIL を同じ JSON 節の `initialization_only_controls` に記録した。

### 再配置直後の FLD 境界同期候補

試験専用 [threelevel_facecell_test_only.patch](threelevel_facecell_test_only.patch) で固定limiter・振幅 `0.1` のlevel 1→2、`x1=0.5` に接する粗側256セルの中心値、ghost値、共有係数、`Dbar`、`DEbar` と面項を出力し、1/2 MPI rankで同じ物理セルを比較した。**共有係数と `Dbar` は256セルすべてで完全一致**。中心値とghost値は各セルで変わり、最大差はそれぞれ `1.1973e-12 / 1.1970e-12`。内部の `ghost-center` は約 `3.035e-12` しかなく、rank間の差は最大 `2.22e-16`（binary64のこの値付近での1 ulp）。面項のrank差は最大 `9.04e-10` だった。細側の積分流束は4面ともrank間で表示精度まで一致し、粗側積分流束だけ `7.06e-15` または `2.82e-14` 異なった。256セルの面項差を体積・時間係数で再集計すると、粗側面差を各面 `~6.5e-26` 以下の差で再現した。したがって**観測されたrank依存の面差は、共有係数のrank差ではなく、微小なdouble状態差を小さい面勾配の差分で評価した結果**と定量的に説明できる。

この試験でも1/2 rankのTest Cの単精度HDFは全要素完全一致する。試験専用診断ON/OFFでも各rankのHDFは全要素一致した。HDFでは見えない内部doubleの差があるため、HDF一致を面項のbitwise一致の根拠にはしない。

候補としてFGMRESの `batched_reductions=false` も同じ試験専用ビルドで1/2 rank再実行した。両rankともNewton/FGMRESは11+11反復で収束したが、面相対差は `9.72e-6 / 1.03e-5` と引き続き **FAIL**。内部中心値のrank差は最大 `8.45e-12`、面勾配差は最大 `4.44e-16` に増えた。共有係数と `Dbar` は全256セル一致し、単精度HDFもrank間一致した。batched reductions無効化は解決策として取り消す。状態差がFGMRESのどのMPI演算で生じたか、粗細面の相対FAILを厳密に消す演算方法は未確定。4 runの入力/Git/binary/patch SHA、全反復・true residual、面・energy ledger、時間/RSS、PASS/FAIL、256セル比較はJSONの `threelevel_rank_facecell_probe` に保存した。診断は試験専用で、追跡する本番演算子と閾値は変更しない。
