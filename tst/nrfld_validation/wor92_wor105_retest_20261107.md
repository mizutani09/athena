## Same-binary A/B outcomes

The table runs used 32³ root, CFL=0.3, 2 MPI ranks, `dt` initially
`31.114819909`, flux-form matvec, exact mixed-frame local gas trial,
FGMRES target `2e-8`, restart 10, 300 max iterations, one MG cycle, and
precision-floor factor 16 unless marked strict. All comparisons within a
mesh used the identical input and binary; only the conservative-route
environment flags differed. The ideal controls used the same mesh and
solver settings, constant opacity and ideal EOS; initial `dt` was
`31.084769248`.

The 16³ case refined **all** root blocks: 64 level-1 leaves and no
coarse/fine boundary. The 8³ case genuinely had 56 level-0 and 64 level-1
leaves. Thus the 16³ success cannot establish coarse/fine correctness. In
the 8³ table run, turning tangential reconstruction off changed the first
linear failure from `0.484` to a three-cycle run with three precision-floor
acceptances. All three Newton solves converged in two iterations, with
maximum final L2 `5.40e-7` and max norm `4.87e-6`. The ideal 8³ run with
tangential off had 13/13 **strict** FGMRES solves, maximum true residual
`1.9706e-8`, and three strict Newton solves. Turning tangential on caused
large first-cycle FGMRES failure in **both** EOS configurations. This
strongly implicates that reconstruction path in the coupled mixed-level
operator/preconditioner, but does not yet locate the defective row.

Table strict controls remain unresolved. At 16³, disabling precision-floor
acceptance stopped in cycle 0 at `8.99e-8`; restart 20 plus two MG cycles
still stopped at `9.12e-8`. At genuine mixed-level 8³ with tangential off,
that stronger strict control completed one cycle, then stopped at
`6.33e-8`. These values are above `2e-8`; increasing max iterations alone
would not establish convergence. The floor-accepted three-cycle table run
is a useful pilot, **not a strict-linear pass**.

At the 8³ tangential-on failure, the true residual was `0.484` and the
local-stencil componentwise backward-error proxy was `1.21e-4` (AMR ghosts
are interpolated, so this is not the assembled global error). The same
operator's additivity/homogeneity errors were `2.97e-16`/`5.01e-16`.
The local Jacobian check on 343 interior cells of block 0 had gas relative
L2 discrepancies `9.77e-5 → 9.77e-6 → 9.80e-7` as the finite-difference
step fell by decades; radiation differences grew from `7.51e-12` to
`6.80e-10` near roundoff. These checks do not exercise the coarse/fine
interface or the MG preconditioner.

## Conservation and existing regression

Opt-in implicit energy/interface ledgers were enabled for separate A/B
repeats. At 16³, the legacy first-cycle domain interior diffusion sum was
`+3.12246e8`; the conservative three-cycle total was `+7.83e-9`.
That mesh has only same-level leaf faces. At 8³, the legacy first-cycle
interior sum was `-2.78088e8`; conservative tangential-off sums over the
three cycles were `+217.3`, `+35.3`, and `-168.8` code-energy units.
The x1-plane audit reported maximum coarse/fine relative mismatch
`8.49e-2 → 1.98e-7`. The latter is greatly reduced but **not roundoff**;
the audit covers x1 planes and MPI stdout can interleave. Full 3D
conservation and interface rows remain to be verified.

The existing WOR-105 Test C N=32 diffusion-mode regression passed in
serial on this source. Conservative/series face mismatch was
`3.70e-15` versus legacy `5.14e-3`, and the conservative global diffusion
ledger was `-1.32e-20`. The 2-rank version's parser falsely reported a
missing face because two ranks interleaved an interface-ledger line in
stdout; raw outputs and logs are retained, and this MPI parser needs repair
before using it as a gate.
