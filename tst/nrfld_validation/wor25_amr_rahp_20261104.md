# WOR-25: AMR interface R A_h P control (2026-11-04)

The existing uniform-grid diagnostics already compare the production
rediscretized hierarchy with the actual V-cycle correction and establish the
benefit of uniform Galerkin for the RSG problem. This follow-up isolates the
coarse/fine placement in the independent x-only fixed-limiter Test C model
validated against Athena's first correction in
`wor23_wor24_operator_audit_20261023.md`.

`test_c_amr_rahp_reference.py` uses the same 96-leaf composite MG operator as
that reference. `P` linearly interpolates the uniform 64-cell root correction
onto refined leaves; `R` volume-averages leaves into root cells. The root
rediscretized operator is compared to `R A_h P` on a constant field, a smooth
sine, the pulse, the restricted initial right-hand side, a root coarse solve,
and the restricted exact 96-cell MG direction. Refinement intervals
`[0.25,0.75]` and `[0.125,0.625]` have the same 96 leaf cells and finest dx.

| q | Interface placement | Pulse relative L2 | Restricted actual direction relative L2 | Fraction of pulse mismatch at interface |
| ---: | --- | ---: | ---: | ---: |
| 1e4 | aligned | 4.99e-5 | 5.55e-5 | 0.001 |
| 1e4 | shifted | 8.43e-3 | 7.34e-3 | 1.000 |
| 1e7 | aligned | 8.05e-8 | 6.78e-8 | 0.784 |
| 1e7 | shifted | 8.44e-3 | 7.35e-3 | 1.000 |

The constant row is exact in every case (both fine and root diffusion row
sums are zero). The smooth sine has a 2.36–3.45% relative difference, localized
to the interface. In the shifted case, the pulse and actual-direction mismatch
is about 0.7–0.8%, and the entire pulse mismatch is at the interface. Moving
the same 96-leaf refinement interval away from the pulse reduces these
particular mode mismatches by orders of magnitude. This supports the placement
sensitivity seen in Test C; it does not establish that this mismatch alone
causes the nonlinear solve failure.

This is an **independent x-only composite model**. Its root-to-leaf `P` and
leaf-volume `R` are explicitly defined references, not a measurement of
Athena's production octet/root transfer, MPI boundary communication, or a
collapse restart. The next WOR-25 measurement must instrument the production
AMR V-cycle at the octet/root handoff and compare its actual coarse correction
using the same fine and coarse operator/ghost state. Uniform production
Galerkin cannot be assumed to work on the AMR interface.
