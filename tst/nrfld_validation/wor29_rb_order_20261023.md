# WOR-29: NR-FLD red-black smoothing order audit (2026-10-23)

## Scope

This audit changes only `nrfld/symmetric_rb_sweeps`.  It uses the same
single-rank, periodic, radiation-only Test C executable and fixed timestep as
the WOR-23--25 controls.  It does not establish symmetry of the complete AMR
multigrid preconditioner or validate a collapse calculation.

## Actual call order

At V-cycle entry `SolveVCycle` toggles `coffset_`.  MeshBlock task lists call
`SmoothBlock(0)` and then `SmoothBlock(1)`.  `linearMG::Smooth` subsequently
applies `color ^= coffset_`.

- `symmetric_rb_sweeps=false`: downward and upward MeshBlock smoothing use the
  same order within a V-cycle; the order alternates between V-cycles.
- `symmetric_rb_sweeps=true`: `coffset_` is toggled after the coarsest solve,
  so upward/post smoothing reverses the downward/pre order.  The starting order
  still alternates between V-cycles.

The octet/root path contains an extra distinction.  With the option disabled,
`OneStepToCoarser/Finer` passes `first_color=coffset_`, after which
`linearMG::Smooth` XORs by the same offset.  Its effective first color is
therefore always zero.  With the option enabled it passes zero, and the
effective order follows (and on the upward leg reverses with) `coffset_`.
Consequently the disabled mode is not one globally uniform color-order policy
across MeshBlock and octet/root levels.

Reversing red-black order is an adjoint-like smoother pairing only when the
same linear operator and boundary exchange are used.  It does not by itself
make an AMR V-cycle symmetric when the coarse operator is rediscretized and
restriction/prolongation are not an adjoint pair.

## Numerical controls

The independent uniform reference reproduces the Athena first-cycle factors:

| variable-limiter case | same pre/post order | reversed post order |
|---|---:|---:|
| q=5e5 | 0.936206935 | 0.978303460 |
| q=7e5 | 1.020718730 | 1.057141037 |

Thus reversal makes both controls less effective.  q=5e5 still converges, but
Athena requires 4 Newton iterations instead of 3.  q=7e5 is rejected in both
modes and is worse with reversal.

For fixed-lambda q=1e7 at NR tolerance 1e-7:

- uniform fine: converges in 2 Newton iterations in both modes;
- aligned AMR: converges in 4 iterations with 3 rejected V-cycles in both;
- shifted AMR: fails after one Newton iteration in both.

The aligned radiation-energy drift is `-5.1434268e-5` versus
`-5.1434279e-5`; the shifted final normalized L2 residual is 0.658334119 in
both to the shown precision.  Order reversal does not explain the shifted-AMR
operator mismatch.

## Conclusion

`symmetric_rb_sweeps=true` is not a remedy for the Test C failures and is
numerically worse for the uniform variable-coefficient control.  The option
should not be described as guaranteeing symmetry of the full V-cycle.  Before
changing its production default, the MeshBlock versus octet/root color-policy
inconsistency should be resolved and MPI/collapse comparisons completed.
