# WOR-24 / WOR-25: centered coarse/fine flux and FGMRES update trial

## Provenance and scope

This work uses independent branch `codex/wor24-centered-wor25-roundoff-20261107`, based on validated commit `2d6821233229ed68bc172ed94d85b0d81243736d`. The candidate source is commit `e786abc429684cf413d23f423b6d48df5838437d`; its final isolated build has binary SHA-256 `1b47730af10734229823cd2347a3c003e8dfd1370ee5c32997092049d8fc9d66`. Earlier runs used intermediate binaries identified individually below and in the JSON. The original worktree and the WOR-92 branch were not modified or merged. WOR-92 mechanism report commit `6ac9288f` was read from its remote branch. All runs used the local PC and isolated MPI builds under `/tmp/wor24_centered_wor25_roundoff_*_build`. The candidate is gated by `ATHENA_NRFLD_CENTERED_FACE_TRIAL=1` and scoped to Test C; the default operator is unchanged. A supported conservative Test C run rejects the flag if the legacy difference-Jv path is also requested. The candidate is not enabled for Mach 5 without separate validation.

The final build used the `nrfld_diff_amr_interface` problem, Cartesian adiabatic hydro, MPI, HDF5 double output, and `NRMGFLD_ENABLED=1` (`mpicxx -O3 -std=c++11`).

The opt-in candidate forms each fine coarse/fine face moment as `D*(Er - tangential_offset - coarse_cell_reference)`. It uses the same shifted moment for the Newton residual, conservative coarse face, FGMRES correction matvec, and interface ledger. The correction moment is exchanged through the existing interface boundary variable after correction ghost synchronization. A physical boundary is excluded from this coarse/fine path. No AMR Galerkin operator was added.

## WOR-25 relation

The WOR-92 mechanism report measured a tiny requested FGMRES update that was rounded when added to a double-precision solution vector, with the operator amplifying that difference. An opt-in `ATHENA_NRFLD_FGMRES_UPDATE_AUDIT` measured the same requested/realized update, independently predicted residual, and amplified gap in the WOR-25 two-step Test C solve. With the centered face candidate enabled, cycle 1's first linear solve failed the strict `1e-8` gate after 80 FGMRES iterations. At iteration 80 the projected and independently predicted relative residuals were `1.604606e-9` each, whereas the true relative residual was `3.695020e-8`. The requested/realized update differed by `6.988e-15` in L2; applying the operator to that representational gap gave `3.691970e-8` relative to the right-hand side. Thus the face fix does not remove the separate FGMRES residual floor. The trial binary SHA-256 was `2a45a893a194ea93c4dcf9e7ae1329216195bbb653e03cd38bee4d97041ba6a4`; the run exited 134 with the solver's fatal threshold error after 4:12.23 and peak RSS 464504 kB.

The isolated [long-double restart-sum trial](wor25_long_double_restart_update_test_only.patch) added each Arnoldi basis correction in `long double` and rounded the resulting iterate once to `Real` (binary SHA-256 `bbc33e37518295cee6a93d81300d1f8b4237ef72c182a3cb7fbab13b8c6a87fd`). It also failed at the corresponding cycle-1 solve: after 80 iterations the projected relative residual was `1.540291e-9`, true relative residual `3.521754e-8`, exit 134, wall 6:32.61, peak RSS 462536 kB. This improves the true residual by about 4.7% but does not reach `1e-8`; the trial was removed from tracked solver source. The retained patch is evidence only.

Setting the input FGMRES true-residual target to `5e-8` allowed the centered, variable-limiter two-step run to complete the first step, but the second step's third linear solve reached another representation floor: after 80 iterations the projected relative residual was `2.285e-9` and the true relative residual `5.616e-8` (exit 134, 6:30.05, 462444 kB). A single fixed cap is therefore not established by this run. A separate `1e-7` trial and an opacity-x1000 strict control are being evaluated; neither changes the production input or solver policy.

With a `1e-7` **trial input** target, the centered variable-limiter case completed both steps on one rank: Newton converged in 16 and 7 iterations with final normalized L2 `2.103e-9` and `1.053e-8`; 23 FGMRES solves used 325 iterations, with maximum explicitly recomputed true relative residual `9.950e-8`. Twenty coarse/fine face pairs across both cycles had zero printed relative mismatch, and the largest implicit energy-ledger absolute relative balance was `5.150e-9` (exit 0, 4:56.09, 462000 kB). This is a bounded inexact-Newton pilot, not strict `1e-8` convergence or a general tolerance recommendation. The two-rank reproduction also completed: 16+7 Newton iterations, 23 FGMRES solves and 325 iterations, maximum true relative residual `9.945e-8`, twenty face pairs at most `1.007e-16`, energy-ledger balance at most `6.987e-9` (exit 0, 3:09.61, 255336 kB). All final numeric HDF arrays were exactly equal between ranks. Rank 2 used the final Test C scoped build SHA-256 `42f84993ea6468767459617cccbccee1e03024471c0b83d9ed1261c608b09176`. The different rank counts have slightly different double-precision residuals, as expected; the equal iteration totals and HDF arrays show local reproducibility for these two steps.

The same `1e-7` **input trial** was extended to five steps on the exact committed final source/binary on 1/2 ranks. Both converged Newton in `16+7+5+4+3` iterations; 35 FGMRES solves used 445 iterations. The largest recomputed true relative residual was `9.949735e-8` / `9.945445e-8`. Fifty coarse/fine face pairs had largest relative mismatch `0` / `1.0074e-16`, and the largest implicit energy-ledger absolute relative balance was `5.150e-9` / `6.987e-9`. The fifth Newton final normalized L2 was `1.787888e-9` on both ranks. All final numeric HDF arrays matched exactly. Wall time was 5:45.73 / 4:10.73 and peak RSS 462000 / 255508 kB, with both jobs active together. This longer local pilot supports the bounded inexact route for this specific trajectory but does not establish a general acceptance policy or satisfy strict `1e-8` FGMRES convergence.

With the **same final binary, input, and `1e-7` target but centered face OFF**, the five-step attempt stopped on cycle 1 (the second step) on both 1/2 ranks. The first step converged in 16 Newton iterations; the second exhausted backtracking after 10/7 Newton iterations. All completed FGMRES solves remained under the input target (maximum true relative residual `9.960e-8` / `9.965e-8`), so this is a nonlinear failure rather than a linear target failure. The coarse/fine face mismatch reached `1.390e-3` / `3.205e-3`; the direct runs exited 134 after 1:48.76 / 0:51.57 with peak RSS 462456 / 255604 kB. The first completed step's available HDF numeric arrays were exactly equal between ON and OFF at each rank, but these outputs do not contain the full hidden solver state.

To separate that first-step trajectory from the operator used on the second step, an ON run wrote a common accepted checkpoint after cycle 0 (`SHA-256 ff71680ddde9db77d762983222c86151c16093853bae83ce59b664b6a6842993`). The **same checkpoint** was restarted twice on one rank, changing only the centered-face flag; both runs reported `path=conservative`. ON converged in seven Newton iterations with seven FGMRES solves/70 iterations, largest true residual `6.292e-8`, ten face pairs with zero printed mismatch, and energy-ledger balance at most `5.252e-9` (exit 0, 1:09.39, 458292 kB). OFF exhausted Newton backtracking after 11 iterations, despite all 12 FGMRES solves/115 iterations meeting the `1e-7` true-residual target (maximum `6.846e-8`); its final normalized Newton L2/max were `9.030e-9` / `1.797e-7` (exit 134, 1:25.39, 454244 kB). This common-state control shows that the second-step operator choice itself affects local Newton acceptance. It does not prove a universal cure. The generated input SHA, exact commands, checkpoint hash, per-solve histories, resource data, and PASS/FAIL are recorded by [`record_wor24_common_checkpoint_20261107.py`](record_wor24_common_checkpoint_20261107.py) in [`wor24_common_checkpoint_20261107.json`](wor24_common_checkpoint_20261107.json).

Step 1 had converged in 21 Newton iterations, and all completed FGMRES solves had true relative residual below `1e-8`. The repeat with a 600 s local timeout and Test C scoped build SHA-256 `42f84993ea6468767459617cccbccee1e03024471c0b83d9ed1261c608b09176` completed both steps: Newton 21+4 iterations, 25 FGMRES solves and 293 iterations, largest true relative residual `8.806e-9`, twenty face pairs at most `7.228e-17`, and implicit energy balance at most `5.735e-12` (exit 0, 4:36.70, 462044 kB). The two-rank reproduction with the exact final-source binary SHA-256 `1b47730af10734229823cd2347a3c003e8dfd1370ee5c32997092049d8fc9d66` also completed 21+4 Newton iterations and 25 solves/293 FGMRES iterations, with largest true residual `8.807e-9`, twenty face pairs at most `7.228e-17`, implicit energy balance at most `6.932e-12`, exit 0, 2:06.81, and 255204 kB peak RSS. All final numeric HDF arrays matched exactly across ranks. The second Newton final L2 was `5.979e-8`, below its `1e-7` gate. Timeout RSS from `/usr/bin/time` describes the wrapper, so it is excluded from peak-memory conclusions.

The exact final-source binary also passed one-step, **two-level** shifted Test C with coupled variable limiter and strict `1e-8` on 1/2 ranks. Newton took 16 iterations on both. Sixteen FGMRES solves used 593/594 iterations, with largest true relative residual `9.862e-9` / `9.838e-9`; the ten coarse/fine face pairs had largest relative mismatch `5.787e-17` on both. ## AMR redistribution and restart

The existing WOR-106 coupled restart driver was rerun with the final candidate binary and the centered flag enabled, using its `nrfld_diff_amr_interface` input, five-cycle limit, variable limiter, and `const_opacity=0.004`. The generated input hashes, exact commands, 1/2-rank choices, every Newton/FGMRES true-residual history, face/energy ledgers, wall time, memory, final HDF hashes, and PASS/FAIL are in [`wor24_centered_restart_20261107.json`](wor24_centered_restart_20261107.json), produced by [`record_wor24_centered_restart_20261107.py`](record_wor24_centered_restart_20261107.py).

The three **candidate conservative** paths (static 2→2 ranks, adaptive 2→2, adaptive 1→2) all completed direct and restarted runs. Adaptive AMR changed the leaf count from 18 to 4; static stayed at 18. For all three, the final time, topology, and **all numeric HDF datasets** matched exactly between direct and restarted runs (`user_out_var` maximum absolute difference zero). The direct runs' strict FGMRES true residuals were at most `9.9341e-9`; their coarse/fine face mismatch was at most `6.2452e-17`, and the maximum implicit energy-ledger absolute relative balance was `1.732e-13`. Direct FGMRES totals were 314/296/296 iterations, respectively; restart segments used 80/62/62. The corresponding legacy baselines also restarted exactly but had coarse/fine face mismatch `0.260–0.264`. These legacy runs are controls for restart and routing, not a centered-face ON/OFF comparison within the conservative operator. The matched conservative ON/OFF face comparison is the three-level one-step experiment above.

A same-case, centered-flag-OFF two-step control with the vector-closure update audit (binary SHA-256 `2e9e544908197d0dc915ff24f42e4dc01047a81c708dee914734dad9a9378b8c`) also failed on cycle 1's first linear solve: 80 iterations left projected/predicted relative residuals `1.709104e-9`, true residual `4.151283e-8`. The requested versus realized update differed by `6.840e-15` in L2; `A` applied to that difference was `4.133315e-8` relative to the right-hand side. The vector closure `||(r_true-r_predicted)-A(update_gap)||/||b||` was `4.541e-9`, about 11% of the amplified update gap. Thus the double-update amplification dominates on both the old and centered face paths, although operator evaluation and rounding contribute a smaller remainder. The control exited 134 after 6:43.58, peak RSS 464372 kB. Its `4.15e-8` floor and the centered path's `3.70e-8` floor are local trajectory-dependent values, not a general performance ordering.

## Remaining validation before default use

The centered candidate has a strict multi-step Test C completion at opacity x1000; the original strong-diffusion case still hits a double-precision FGMRES residual floor on step two, so a strict multi-step result there and a performance decision remain. Mach 5 is outside this trial’s enabled scope and requires a separate validation before generalization. WOR-25 needs a justified mitigation trial for its identified representational floor. These items remain In Progress.
